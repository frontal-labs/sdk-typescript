# Webhooks Examples

This directory contains examples demonstrating how to use the Frontal Webhooks SDK.

## Available Examples

### endpoint-management.ts
Endpoint CRUD, secret rotation, delivery tracking with retry, and webhook statistics.

**Run**: `bun run endpoint-management.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
