# Events Examples

This directory contains examples demonstrating how to use the Frontal Events SDK.

## Available Examples

### pub-sub.ts
Topic creation, event publishing, subscription management (pause/resume).

**Run**: `bun run pub-sub.ts`

### dead-letter.ts
Dead-letter queue listing, event replay, and queue purge.

**Run**: `bun run dead-letter.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
