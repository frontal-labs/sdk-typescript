# Queues Examples

This directory contains examples demonstrating how to use the Frontal Queues SDK.

## Available Examples

### jobs-and-workers.ts
Queue creation, job enqueuing with scheduling, job listing by status, retry handling, pause/resume.

**Run**: `bun run jobs-and-workers.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
