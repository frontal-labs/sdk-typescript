# Lineage Examples

This directory contains examples demonstrating how to use the Frontal Lineage SDK.

## Available Examples

### graph-and-impact.ts
Lineage graph retrieval with depth, node listing by type, trace full lineage, impact analysis of changes, edge listing.

**Run**: `bun run graph-and-impact.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
