# Schedules Examples

This directory contains examples demonstrating how to use the Frontal Schedules SDK.

## Available Examples

### cron-jobs.ts
Cron expression validation, run preview, schedule CRUD, manual trigger, run listing with cancel, pause/resume.

**Run**: `bun run cron-jobs.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
