# Datasets Examples

This directory contains examples demonstrating how to use the Frontal Datasets SDK.

## Available Examples

### crud-and-data.ts
Dataset CRUD, row insertion, querying with filters, version creation and comparison, statistics.

**Run**: `bun run crud-and-data.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
