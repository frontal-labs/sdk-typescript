# Flags Examples

This directory contains examples demonstrating how to use the Frontal Flags SDK.

## Available Examples

### evaluation-and-rollouts.ts
Flag creation, user-context evaluation, bulk evaluation, gradual rollout with pause/resume.

**Run**: `bun run evaluation-and-rollouts.ts`

### experiments.ts
A/B experiment creation with variants, start/stop lifecycle, and result analysis.

**Run**: `bun run experiments.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
