# Sandbox Examples

This directory contains examples demonstrating how to use the Frontal Sandbox SDK.

## Available Examples

### execution.ts
Template listing, sandbox CRUD, code execution, SSE output streaming, file upload/list, snapshot, lifecycle management.

**Run**: `bun run execution.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
