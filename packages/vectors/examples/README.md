# Vectors Examples

This directory contains examples demonstrating how to use the Frontal Vectors SDK.

## Available Examples

### search-and-index.ts
Index creation with dimensions and metric, vector upsert, similarity search (top-k), hybrid vector+text search, deletion.

**Run**: `bun run search-and-index.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
