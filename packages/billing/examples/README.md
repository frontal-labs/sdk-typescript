# Billing Examples

This directory contains examples demonstrating how to use the Frontal Billing SDK.

## Available Examples

### subscriptions-and-invoices.ts
Plan listing, subscription status and plan changes, invoice history (paginated), usage reporting, payment methods.

**Run**: `bun run subscriptions-and-invoices.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
