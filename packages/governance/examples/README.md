# Governance Examples

This directory contains examples demonstrating how to use the Frontal Governance SDK.

## Available Examples

### policies-and-rbac.ts
Policy CRUD with enable/disable, policy evaluation with context, RBAC binding creation and access checking.

**Run**: `bun run policies-and-rbac.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
