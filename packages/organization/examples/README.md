# Organization Examples

This directory contains examples demonstrating how to use the Frontal Organization SDK.

## Available Examples

### tenants-and-teams.ts
Organization fetch, tenant CRUD, team CRUD with member assignment.

**Run**: `bun run tenants-and-teams.ts`

### members-and-roles.ts
Member invitations, role creation with permissions, member role updates.

**Run**: `bun run members-and-roles.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
