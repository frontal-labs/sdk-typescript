# Audit Examples

This directory contains examples demonstrating how to use the Frontal Audit SDK.

## Available Examples

### trails-and-reports.ts
Event logging, querying with time ranges, CSV/JSON export, audit trail CRUD, compliance checks.

**Run**: `bun run trails-and-reports.ts`

## Getting Started

```env
FRONTAL_API_KEY=your_api_key_here
```

```bash
bun run <example-file>.ts
```
