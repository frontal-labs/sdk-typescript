# Frontal SDK Roadmap

The following packages are available:

- @frontal-labs/core — Shared transport, auth, retries, pagination
- @frontal-labs/sdk — Unified SDK client for all Frontal services
- @frontal-labs/testing — Shared test utilities and fixtures
- @frontal-labs/ai — AI inference, embeddings, and streaming
- @frontal-labs/agents — AI agent integrations and workflows
- @frontal-labs/audit — Audit trails and compliance checks
- @frontal-labs/auth — Authentication with MFA, OAuth, SSO
- @frontal-labs/billing — Plans, subscriptions, invoices
- @frontal-labs/blob — Object storage (S3/Blob compatible)
- @frontal-labs/connectors — Data ingestion connectors
- @frontal-labs/datasets — Dataset CRUD with versioning
- @frontal-labs/events — Pub/sub event bus
- @frontal-labs/flags — Feature flags and A/B experiments
- @frontal-labs/functions — Serverless functions
- @frontal-labs/governance — Policy management and RBAC
- @frontal-labs/graph — Business entity CRUD and semantic search
- @frontal-labs/integrations — Third-party integrations
- @frontal-labs/lineage — Data lineage and impact analysis
- @frontal-labs/observability — Logs, metrics, traces, alerts
- @frontal-labs/ontology — Schema management and AI inference
- @frontal-labs/organization — Multi-tenancy and team management
- @frontal-labs/pipelines — Declarative data pipelines
- @frontal-labs/queues — Job and message queues
- @frontal-labs/sandbox — Isolated code execution
- @frontal-labs/schedules — Cron-based scheduling
- @frontal-labs/search — Unified cross-service search
- @frontal-labs/vectors — Embeddings store and similarity search
- @frontal-labs/webhooks — Webhook endpoint management
- @frontal-labs/workflows — Workflow orchestration
